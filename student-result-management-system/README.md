Student Result Management System

A Dart console-based application that calculates and displays students' academic performance.

Project Features

Stores student information.

Stores five subjects and their scores.

Calculates total score and average.

Determines students' grades.

Generates performance remarks.

Determines whether a student passed or failed.

Displays a complete student result report.
