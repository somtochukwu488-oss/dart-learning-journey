Daily Habit Tracker

Project Description

A simple console-based application built with Dart to track daily habits and monitor completion progress.

Features

Stores multiple daily habits.

Tracks completed and incomplete habits.

Displays all habits and their statuses.

Calculates completed and incomplete habit counts.

Displays a final progress summary.

Dart Concepts Practised

Variables and data types

Lists

Boolean values

For loops

If/else statements

String interpolation

Accumulators

List length

What I Learned

This project helped me practise using lists, loops, conditional statements and accumulators to solve a practical problem independently.
